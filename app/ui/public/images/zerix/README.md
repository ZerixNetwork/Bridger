# Zerix branding assets

Original Zerix branding assets used by the application:

- `logo.png` — transparent horizontal logo used inside the application.
- `favicon.png` — browser icon.
- `icon.png` — Electron/application icon.
- `legacy-artwork.jpg` — archived previous Zerix artwork; not displayed in the application.

The favicon and application icon intentionally share the same source artwork.
